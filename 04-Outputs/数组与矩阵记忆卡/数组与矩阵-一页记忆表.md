# 数组与矩阵 · 记忆速查表

每天最多 3 道新题。先遮住答案复述，再核对；每天选 1 道合上答案写代码。

| 题目 | 一句话思路 | 容易错的地方 |
|---|---|---|
| 238 · 除自身以外数组的乘积 | 左边乘一遍，右边补一遍。 | 先写答案，再更新累计量；顺序反了就会把自己乘进去。自测 [0,2,3] → [6,0,0]；[0,0,3] → [0,0,0]。 |
| 56 · 合并区间 | 起点排队，重叠就延长右边。 | [1,4] 和 [4,5] 在本题中要合并。包含关系也要用 max，不能直接覆盖右端点：[[1,10],[2,3]] → [[1,10]]。 |
| 73 · 矩阵置零 | 首行首列做标记，自己的命运先记起。 | 不能发现零就立即清整行，否则新造出的零会继续传播。自测 [[0,1],[1,1]] → [[0,0],[0,1]]。 |
| 189 · 轮转数组 | 全翻，前 k 翻，剩下再翻。 | k 可能大于 n，也可能为 0。Python 的 nums[:k] 会复制数组；要满足 O(1) 额外空间，用双指针交换。 |
| 48 · 旋转图像 | 先转置，再把每行倒过来。 | 转置时遍历整个矩阵，会交换两次又回到原位。转置后反转的是每一行，不是行的排列顺序。 |
| 53 · 最大子数组和 | 前面拖后腿，就从这里重来。 | best 不能初始化为 0：[-5,-2,-8] 的答案是 −2。cur 是“以这里结尾”，不等于全局最优。 |
| 54 · 螺旋矩阵 | 右下左上，走完一边缩一边。 | 走下边前判断 top ≤ bottom；走左边前判断 left ≤ right。只有一行或一列时，不检查就会重复访问。 |
| 240 · 搜索二维矩阵 II | 右上出发，大了往左，小了往下。 | 不要从左上角出发：右边和下边都更大，无法决定排除哪边。此题不能直接把矩阵摊平成整体有序数组做二分。 |
| 41 · 缺失的第一个正数 | 数字 x 坐 x−1，第一空位就是答案。 | 必须检查 nums[j] != nums[i]，否则重复值会造成死循环。先存目标索引 j，避免交换过程中又用已变动的 nums[i] 计算目标。 |
| 66 · 加一 | 逢九变零，非九加一就停。 | 只改最后一位不够。全为 9 时，结果长度会增加 1；[0] 加一是 [1]。 |
| 36 · 有效的数独 | 行、列、宫，三本账都查重。 | 这里检查当前是否合法，不判断最终是否可解。宫编号用整除 //，不是取模 %；空格不参与查重。 |
| 57 · 插入区间 | 左边照抄，中间合并，右边接上。 | 本题相接端点也合并。空列表要返回 [newInterval]；不能忘记把合并后的新段加入结果。 |
| 435 · 无重叠区间 | 结束越早越先留，撞上就删后来者。 | 这题要保留更多段，按结束时间排；56 合并区间按开始时间排。start == previous_end 时可以保留。 |
| 252 · 会议室 | 起点排队，后开不能早于前结束。 | 严格小于才冲突，相等可以参加。此题只问能否参加全部，不能删掉冲突会议后回答 True。 |
| 253 · 会议室 II | 结束时间放小堆，同时在开的最多要几间。 | 本卡的堆表示活跃会议，因此要弹出所有已结束会议，返回历史峰值。别和“只复用一个房间，返回最终堆长”的另一种写法混用。 |
| 1851 · 包含每个查询的最小区间 | 查询从小扫，能进就入堆，过期顶上清。 | 闭区间长度是 right−left+1。过期条件是 right < q。堆按长度排，并不保证所有过期区间都在顶部；只需保证最终堆顶有效。 |
| 43 · 字符串相乘 | 个位 i+j+1，进位往左存。 | 先加上结果位已有的值，进位用 +=。必须处理 '0'，否则去前导零后可能得到空串。 |
| 2013 · 检测正方形 | 同列找边，两侧补点，次数相乘。 | 同列找的是邻点，不是对角点。side 不能为 0；左右两侧都要查；查询点自身无需已被添加，也不乘它的出现次数。 |

## 每次问自己

1. 什么条件让我想到这种办法？
2. 关键变量一直代表什么？
3. 什么输入会让错误写法露馅？

认出、讲清、写出分开评价。隔 1、3、7、14、30 天回忆是可调整的起点；忘了先缩短间隔。
